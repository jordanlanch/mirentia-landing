El problema

14 horas semanales perdidas en WhatsApp, Excel y agenda manual.

Bailante es una academia de baile en Bogotá con +200 alumnos. El fundador recibía todos los leads por WhatsApp: mensajes de interesados, respuestas a posts, consultas de horarios. Cada lead implicaba:

  • Leer el mensaje y responder manualmente
  • Copiar datos del lead a una hoja de Excel
  • Buscar disponibilidad en Google Calendar
  • Enviar propuesta de horario por WhatsApp
  • Confirmar, agendar, y recordar al cliente antes de la clase

Todo esto, mientras la clase no se dictaba sola. El owner terminaba agotado, sin tiempo para marketing ni mejoras del producto.

La solución

Web + WhatsApp Cloud API + Google Calendar + Retell AI.

Captación automatizada

WhatsApp Cloud API

Leads que llegan por WhatsApp se procesan en segundos: el agente identifica nivel, intereses, disponibilidad y agenda propuesta — sin intervención humana.

Agenda inteligente

Google Calendar + IA

La integración con Google Calendar permite consultar disponibilidad real y agendar clases automáticamente, enviando confirmación y recordatorios 24/7.

Re-engagement

Retell AI

Leads que no concretaron reciben llamadas automatizadas de seguimiento. El agente de voz confirma interés y reagenda si es necesario.

AEO + Schema

JSON-LD Speakable

Markup de Schema.org LocalBusiness y Speakable en la web. Bailante posiciona en búsquedas locales de academias de baile en Bogotá.

Timeline

8 semanas de implementación.

Semana 1-2: Diagnóstico

Mapeo de flujos existentes: WhatsApp → Excel → Calendar. Identificación de cuellos de botella y priorización de automatizaciones.

Semana 3-4: MVP técnico

Integración WhatsApp Cloud API + webhook de leads + agente de respuesta con GPT-4. Primer test con tráfico real.

Semana 5-6: Google Calendar + agenda

Conexión con Calendar real, lógica de disponibilidad, propuesta de horarios automática, confirmación por WhatsApp.

Semana 7-8: Retell AI + polish

Agente de voz para re-engagement de leads fríos. Testing completo, manejo de edge cases, monitoring.
